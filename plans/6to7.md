## Step 1 — build

- core `7.3.13.Final`, tools-orm `7.3.13.Final` (same excludes as on `hibernate-6`; tools 7.3 also brings
  `jakarta.xml.bind-api`, harmless). Logging stays jboss-logging → slf4j.

## Step 2 — core ORM changes (on top of the 6.6 code)

Because `hibernate-6` already removed every 6.x-deprecated call, most 7.0 removals (`save/saveOrUpdate/update/delete`,
`HANACloudColumnStoreDialect`, `SQLServer2012Dialect`, iterator getters) are already gone. What is left:

## Step 3 — Tools

Tools 7.3.13 has the same API as 6.6.58 (javap-identical for every class used), so no source changes are expected
beyond what `hibernate-6` already did. Differences to watch at runtime: `generateAnnIdGenerator()` only emits `@Id`
for Tools' own `EnhancedBasicValue` (fine for reverse-engineered metadata); `OverrideRepository` uses the JDK's
built-in XML parser.

## Decisions

- D1: JPA `cascade = {PERSIST, MERGE, REMOVE}` replaces Hibernate `@Cascade` (whole enum deprecated for removal in 7).
- D2: row 14 reads generator strategy/parameters from Tools' `EnhancedValue` — the only place a reverse-engineered
  model still carries them in 7.
- D3: keep `Configuration` bootstrap (not deprecated in 7); `HibernatePersistenceConfiguration` is only mentioned.
